# Authentication & Authorization

## JWT Bearer Authentication
- Tokens generated by `IJwtProvider` (implemented as `BeaverJwtProvider`)
- Algorithm: HMAC-SHA256
- Configuration via `JwtOptions` (Issuer, Audience, SecretKey, ExpirationMinutes)
- Token sent in `Authorization: Bearer <token>` header

## JWT Claims
- `sub` — User ID (Guid)
- `email` — User email
- `role` — User role (string: "User" or "Admin")

## Token Lifecycle
- Generated on login (`POST /api/auth/login`)
- Refreshed while still valid (`POST /api/auth/refresh-token`) — returns new token with extended expiration
- Logout (`POST /api/auth/logout`) — placeholder, returns 204; actual token removal handled by client
- No refresh token in database — simple rotation (token must be valid to refresh)
- Expiration configured in `appsettings.json` → `Jwt:ExpirationMinutes`

## Current User Access
- `ICurrentUserProvider` — extracts userId and role from HttpContext claims
- `GetUserId()` — returns Guid from `sub` claim
- `GetUserRole()` — returns `UserRole` enum from `role` claim
- Throws `UnauthorizedAccessException` if user is not authenticated

## Roles
- `UserRole.User` — default role on registration
- `UserRole.Admin` — elevated role, granted via `PUT /api/admin/upgrade-to-admin/{id}`

## Authorization Policies
- `AdminOnly` — requires `Admin` role, applied at controller level on `AdminController`

## Ownership Guards
- `ICarSellerGuard.EnsureCanMutate(sellerId)` — checks if current user is the owner OR admin
- Admin bypasses ownership check
- Non-owner gets `UnauthorizedAccessException` → 401

## Password Hashing
- BCrypt via `IPasswordHasher` (BCrypt.Net-Next)
- Hash stored in `User.PasswordHash`
- Verified on login and password change

## Error Mapping
- `UnauthorizedAccessException` → 401 Unauthorized (via `GlobalExceptionMiddleware`)
